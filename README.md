# 🚀 CodeQuest (Stack Overflow Clone)

A full-featured developer community and Q&A platform inspired by Stack Overflow, built with a modern full-stack architecture.

---

### ✨ Key Features
- 🔐 **Authentication & Security:** JWT and NextAuth-based user authentication.
- 💬 **Q&A System:** Ask questions, post answers, voting, and interactive discussions.
- 🌐 **Internationalization (i18n):** Multi-language support for global accessibility.
- 💳 **Subscription & Payments:** Integrated payment gateways via Stripe and Razorpay.
- 📩 **Notifications & PDF:** Automated email/SMS alerts and PDF report generation.
- 🎨 **Modern UI/UX:** Responsive interface built with Tailwind CSS and Radix UI components.

---

### 🛠️ Tech Stack
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, Radix UI, Lucide Icons, i18next
- **Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, Nodemailer, Twilio
- **Payments:** Stripe & Razorpay
